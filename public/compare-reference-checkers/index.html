Reference checkers compared

Since AI writing tools started producing references that don’t exist, a handful of tools check bibliographies for fake, wrong or retracted references. They differ in where they run, what they check against, and what happens to your file. Here is how they compare, including where others do better than BibProfile.

Beyond checking references

  • BibProfile: Profile of the bibliography, missing citations, preprint → published, shareable report.
  • AccuraCite: Checks whether a source supports a claim; suggests citations.
  • Acurio: Checks your text against the sources you upload (paid).
  • citegate: Fails a CI build; scheduled re-checks.
  • bibaudit: Field-by-field checks incl. every author; ISBN checks.
  • ghostcite: CI; reproducible offline runs.
  • CiteScan: Duplicate detection.
  • betterbib: Formatting and journal-name abbreviation.

Which one fits

  • You want to check a .bib before submitting, without installing anything, and get a cleaned file back: BibProfile.
  • Your paper lives in a Git repository and you want every commit checked: citegate or ghostcite: both fail a CI build on a missing or retracted reference. BibProfile has no CI mode.
  • You cite mostly computer-science conference papers: A tool that also queries DBLP, the most complete index of CS venues: citegate, CiteScan, AccuraCite or betterbib. BibProfile relies on Crossref and OpenAlex, which cover most but not all proceedings.
  • You cite many books, datasets or software: bibaudit: it checks DataCite, Open Library and ISBNs. BibProfile counts web pages, software and datasets as “not checkable”.
  • You want to know whether each source actually supports your sentence: AccuraCite or Acurio. BibProfile only checks that references exist and are correct, not what they say.
  • Your references are in Zotero, not a .bib: Zotero itself warns about retracted items in your library, and bibaudit reads a Zotero library directly. Or export a .bib from Zotero and use BibProfile.
  • Your bibliography has more than 300 entries: A command-line tool: BibProfile handles up to 300 entries (1 MB) per file.

What BibProfile doesn’t do

  • No command-line or CI mode: it’s a web app (its source code is public, under the AGPL-3.0).
  • It checks Crossref and OpenAlex only — not DBLP, Semantic Scholar or PubMed directly.
  • It doesn’t check whether a source supports what you cite it for, and doesn’t read Word or PDF files.
  • Up to 300 entries (1 MB) per file, and title searches draw on a free daily pool that can run out on a busy day (your own free OpenAlex key lifts that).

FAQ

Which tool should I use to check a bibliography for fake references?

If you have a BibTeX file and want an answer in a few minutes without installing anything, BibProfile checks every reference against Crossref and OpenAlex in your browser and lists the ones it could not verify. If your paper is in a Git repository, citegate or ghostcite can check it on every commit. If you want to know whether each source supports your claims, AccuraCite or Acurio do that.

Do these tools upload my manuscript or bibliography?

BibProfile reads the file in your browser and only sends lookups (a DOI, or a title, first author and year) to Crossref and OpenAlex. The command-line tools run on your machine and also send lookups to their sources. Web services such as AccuraCite and Acurio receive what you upload; see their own privacy pages.

Why does BibProfile list tools that compete with it?
